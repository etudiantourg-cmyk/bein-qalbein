# بين قلبين | BEIN QALBEIN

تطبيق ويب تقدمي (PWA) للرسائل الزوجية الراقية وأدوات التواصل الأسري، بواجهة عربية واتجاه RTL، مع دعم الإنجليزية والفرنسية.

## تشغيل التطبيق

المشروع واجهة ثابتة؛ لا يحتاج إلى خادم تطبيقات خاص. افتح مجلد المشروع عبر خادم HTTP محلي أثناء التطوير، أو استخدم نشر GitHub Pages.

- صفحة التطبيق: https://etudiantourg-cmyk.github.io/bein-qalbein/
- مستودع المصدر: https://github.com/etudiantourg-cmyk/bein-qalbein

## المزايا

- 14 تصنيفاً للرسائل.
- في العربية: 150 صيغة مركبة لكل تصنيف (2,100 إجمالاً)، مولّدة من رسائل أساسية وخواتيم وليست 2,100 رسالة مستقلة محررة يدوياً. الإنجليزية والفرنسية لديهما حالياً 10 رسائل أساسية لكل تصنيف؛ توسيع المكتبتين إلى مستوى العربية ما زال عملاً متبقياً.
- رسالة يومية، وتحدي لطف يومي ثابت حسب تاريخ الجهاز.
- دليل الحياة الزوجية ونصائح منفصلة للزوج والزوجة.
- المفضلة ومجلداتها، سجل آخر الرسائل، ورسائل خاصة محلية.
- إنشاء رسالة مخصصة، أدوات تهدئة الخلاف، ومشاركة الرسائل أو تحويلها إلى بطاقة صورة.
- استوديو ذكاء اصطناعي اختياري عبر Cloudflare Workers AI.
- نسخ احتياطي واستعادة، تخصيص الألوان والخط، ووضع ليلي.
- دعم العمل دون اتصال بعد اكتمال تثبيت التطبيق وتخزين ملفات الواجهة مؤقتاً.

## البنية

- `index.html`: هيكل الصفحات وعناصر الواجهة.
- `app.css`: نظام التصميم والتجاوب وإتاحة الاستخدام.
- `content-data.js`: الرسائل الأساسية والخواتيم والترجمات ونصائح الدليل وبيانات الأدوات.
- `app.js`: مكتبة المحتوى، الحالة المحلية، التنقل، التصنيفات، المفضلة والأدوات الأساسية.
- `ai-studio.js`: واجهة الذكاء الاصطناعي وطلبات المحرك.
- `sw.js`: تخزين PWA المؤقت واستراتيجية العمل دون اتصال.
- `ai-worker/src/index.js`: API الخاص بتوليد الرسائل.
- `tests/`: اختبارات ثابتة، واختبارات متصفح حقيقي، واختبارات Worker.

للتفاصيل وقرارات التصميم وحدود الأمان، راجع [وثيقة المعمارية](docs/ARCHITECTURE.md) و[دليل محرك الذكاء الاصطناعي](ai-worker/README.md).

## الاختبارات

يعمل فحص الجودة في GitHub Actions على Node.js 22 مع Chromium/Chrome وaxe-core. يشغّل:

```sh
node --test tests/*.test.mjs
```

وتشمل الاختبارات:
- تحليل JavaScript والتحقق من بنية HTML ومعرّفات العناصر.
- اختبار تدفقات المستخدم في Chrome، بما فيها التصنيفات والبحث واللغات والمفضلة والدليل والمظهر.
- فحص إتاحة WCAG آلياً عبر axe-core.
- اختبار استوديو الذكاء الاصطناعي باستجابة محاكاة، دون استهلاك حصة Workers AI.
- اختبار التخزين عند تعذر localStorage، واختبار العمل دون اتصال بعد تثبيت PWA.
- اختبارات API للـ Worker تشمل CORS والتحقق من المدخلات وحجم الطلب ومخرجات النموذج والحد المؤقت.

## الخصوصية والقيود المهمة

- المفضلة والرسائل الخاصة والإعدادات تحفظ محلياً في متصفح الجهاز، ولا توجد مزامنة بين الأجهزة أو حساب سحابي للمستخدم.
- إذا منع المتصفح التخزين الدائم أو امتلأ، يعمل التطبيق بذاكرة مؤقتة ويعرض تنبيهاً بأن التغييرات قد تضيع عند إغلاق الصفحة.
- رمز PIN قفل عرض محلي للمفضلة، وليس تشفيراً لبيانات المتصفح ولا حمايةً من أدوات المطور.
- النسخ الاحتياطي يدوي؛ احفظ ملف النسخة في مكان آمن، ولا تشاركه إذا كان يحتوي رسائل خاصة.
- تفاصيل الموقف التي يكتبها المستخدم في استوديو الذكاء الاصطناعي تُرسل إلى Cloudflare لتوليد الرسالة. تجنب الأسماء الكاملة والبيانات الشخصية الحساسة.
- فحص المحتوى في Worker أولي وليس ضماناً شرعياً أو ضماناً مطلقاً لسلامة كل مخرجات النموذج؛ راجع النص قبل إرساله.
- CORS ليس مصادقة، ومحدد الطلبات الحالي يعمل داخل ذاكرة نسخة Worker الواحدة؛ ليس حداً عالمياً ولا حماية كاملة من الإساءة الموزعة.
- الإشعارات اختيارية ولا يُضمن وصولها بعد إغلاق المتصفح. لا يوجد ادعاء بإشعارات Push خلفية.
- أول تثبيت أو تحديث PWA يحتاج اتصالاً لتنزيل الملفات؛ بعد تخزينها يمكن فتح هيكل التطبيق دون اتصال.

## قرارات المحافظة على البيانات

لا تغيّر أسماء مفاتيح التخزين القديمة `bq_*` ولا تحذفها عند إعادة الهيكلة. عند تعديل مخطط النسخ الاحتياطي، حافظ على قبول النسخ السابقة أو أضف ترحيلاً واختبارات استرجاع قبل النشر.
