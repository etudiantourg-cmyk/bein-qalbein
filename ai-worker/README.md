# محرك الذكاء الاصطناعي لتطبيق بين قلبين

هذا مجلد خادم الذكاء الاصطناعي. لا تضع مفتاح API داخل تطبيق GitHub Pages أو داخل ملفات الواجهة.

## النشر مرة واحدة
1. أنشئ حساباً مجانياً في Cloudflare.
2. افتح Workers & Pages ثم Create Worker.
3. أنشئ Worker باسم `bein-qalbein-ai`.
4. افتح تبويب Edit code، واستبدل محتوى الملف بالكود الموجود في `src/index.js` ثم Deploy.
5. من Settings > Bindings أضف Workers AI binding واسمه `AI`، ثم أعد النشر. (أو انشر من Wrangler مع ملف `wrangler.jsonc` الموجود هنا.)
6. انسخ رابط Worker، ويكون عادة بالشكل `https://bein-qalbein-ai.<your-subdomain>.workers.dev`.
7. افتح تطبيق بين قلبين، ثم «استوديو الرسائل الذكي» > «إعداد الاتصال»، والصق الرابط واحفظه.

## التكلفة والحدود
Workers AI يعرض حصة مجانية يومية مقدارها 10,000 Neurons وفق تسعير Cloudflare الحالي. الحصة ليست عدداً ثابتاً من الرسائل؛ الاستهلاك يختلف حسب النموذج وطول الإدخال والإخراج. على خطة Workers Free تتوقف الطلبات عند نفاد الحصة اليومية، ولا نفعّل أي ترقية أو دفع تلقائي من التطبيق.

## ضوابط المحتوى
يطلب الخادم رسائل محتشمة ومحترمة ومتوافقة مع الآداب الإسلامية العامة، ويرفض الاقتباس غير الموثق والفتاوى. مع ذلك، لا يمكن لأي نموذج ضمان حكم شرعي أو منع كل خطأ؛ راجع النص قبل إرساله.
